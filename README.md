# نگهبان ابری ☁️

مدیریت کامل **دامنه، DNS، پنل پاسارگارد و سرورها (هتزنر، لینود، آروان)** در تلگرام — روی **Cloudflare Workers** اجرا میشود؛ بدون هیچ سروری برای اجرا (یک سرور فقط برای نصب اولیه لازم است).

---

## خلاصه

- ربات تلگرامی که رکوردهای DNS را روی کلادفلر و آروان مدیریت میکند (A / CNAME / AAAA / TXT / SRV / MX)
- تشخیص زیردامنهٔ فِنْدی و تعویض خودکار آن (Host Filter) روی پنل پاسارگارد
- مانیتور SSL، انقضای دامنه و پایش منابع سرور (از طریق «رلهٔ SSH»)
- اعلان و یادآوری خودکار قطعی نودها داخل تلگرام
- مدیریت سرورهای **هتزنر، لینود و آروان**: ساخت، ریبوت، ریست رمز، ارتقا و…
- ساخت خودکار سابدامنه برای رله: فقط آیپی را بفرستید، ربات خودش رکورد A میسازد
- آپدیت خودکار از گیتهاب، داخل خودِ ورکر؛ تبلیغ قابلتغییر روی /start

## پیشنیازها

### 🔐 الزامی (بدون اینها نصب ممکن نیست)

| # | پیشنیاز | راهنما |
|---|---|---|
| ۱ | حساب کلادفلر | داشبورد › My Profile › API Tokens |
| ۲ | توکن API کلادفلر با ۳ دسترسی | [آموزش تصویری ساخت توکن](docs/cloudflare-api-token.md) |
| ۳ | توکن ربات تلگرام | [@BotFather](https://t.me/BotFather) › `/newbot` |
| ۴ | شناسهٔ عددی تلگرام خودتان (مدیر) | [@userinfobot](https://t.me/userinfobot) |
| ۵ | یک سرور لینوکسی (فقط برای نصب) | هر VPS کوچک کافی است |

**دسترسیهای توکن کلادفلر (این ۵ مورد دقیقاً همانهایی است که ربات استفاده میکند):**

| دسترسی | وابسته به | برای چه کاری |
|---|---|---|
| `Account · Workers Scripts · Edit` | اکانت | دیپلوی و آپدیت ورکر |
| `Account · Workers KV Storage · Edit` | اکانت | ساخت KV ربات |
| `Zone · DNS · Edit` | زون (همهٔ دامنهها) | مدیریت رکوردها و ساخت سابدامنهٔ رله |
| `Zone · Zone Settings · Edit` | زون | مشاهده/تغییر تنظیمات هر زون (TLS/کش/…) |
| `Zone · Cache Purge · Purge` | زون | دکمهٔ «پاککردن کش» زون |

> دسترسی `Account · Settings` لازم نیست. اکانتی که هرگز وارد pageٔ Workers نشده ممکن است سابدامنهٔ `workers.dev` نداشته باشد؛ در آن صورت یک دسترسی ششم هم اضافه کن: `Account · Workers Subdomain · Edit`.

### 🔑 اختیاری (بههمراه هر قابلیت)

این توکنها در **خود ربات** (نه در نصب) ثبت میشوند:

| قابلیت | توکن موردنیاز | از کجا بگیرم؟ |
|---|---|---|
| آروان (DNS اروان) | API Key آروان | پنل آروان › تنظیمات حساب › کلید API |
| هتزنر | API Token هتزنر | [console.hetzner.cloud](https://console.hetzner.cloud) › پروژه › Security › API Tokens |
| لینود | Personal Access Token لینود | [cloud.linode.com](https://cloud.linode.com/profile/tokens) |
| مانیتور انقضای دامنه | کلید سرویس WHOIS | مثل WhoisXML / WhoisFreaks با متغیر `WHOIS_API_KEY` |
| چک IPv4 | توکن Global Ping | `GLOBALPING_TOKEN` |
| پایش سرور/SSH | رلهٔ SSH (نصب روی VPS) | [بخش رلهٔ SSH](#راهاندازی-رله-ssh-اختیاری) |

راهنماهای کوتاه: [docs/other-api-keys.md](docs/other-api-keys.md)

## نصب (تکخطی)

روی سرور لینوکسی اجرا کنید:

```bash
bash -c "$(curl -sL https://raw.githubusercontent.com/Aknuun/cloud-guardian/main/install.sh)"
```

اسکریپت به ترتیب میپرسد: توکن API کلادفلر → نام ورکر (پیشفرض `cloud-guardian`) → توکن ربات → شناسهٔ مدیر. تنظیمات در `~/.cloud-guardian/config.json` (فقط شما) ذخیره میشود.

بعد از نصب در تلگرام `/start` بزنید.

> سرور فقط «ابزار نصب» است. بعد از نصب میتوانید آن را حذف کنید؛ ربات مستقل کار میکند.

## آپدیت خودکار 🔄

نسخهٔ جدید از گیتهاب که منتشر شود، ربات **خودش را** آپدیت میکند:

- روی کرون ۱۰دقیقهای، ورکر مخزن را چک میکند و اگر نسخه جدیدتر بود، `worker.js` را دانلود و با همان توکن CF خودش دیپلوی میکند.
- شرط: bindingهای `WORKER_ACCOUNT_ID` و `WORKER_NAME` (در نصب خودکار اضافه میشوند) و توکن CF با دسترسی `Workers Scripts Edit`.
- به مدیر پیام «🔄 آپدیت خودکار: v9.00 ← v9.01» میرسد.

## راهاندازی رلهٔ SSH (اختیاری — برای بخش «سرورها»)

روی یک VPS که میخواهید از آن نظارت شوید:

```bash
sudo bash -c "$(curl -sL -H 'Accept: application/vnd.github.raw' 'https://api.github.com/repos/Aknuun/cloud-guardian-relay/contents/srv-relay-install.sh?ref=main')"
```

سپس در ربات: «🖥 سرورها ← ℹ️ راهنمای رله ← 🔧 تنظیم رله» — فقط آیپی را بفرستید.

## متغیرهای اختیاری (bindings ورکر)

| متغیر | توضیح |
|---|---|
| `WHOIS_API_KEY` / `WHOIS_API_PROVIDER` | API اعتبارسنجی انقضای دامنه |
| `GLOBALPING_TOKEN` | توکن Global Ping برای چک IPv4 |
| `SRV_RELAY_URL` / `SRV_RELAY_TOKEN` | رلهٔ SSH پیشفرض (در ربات هم قابل ثبت است) |
| `HF_RELAY_URL` / `HF_RELAY_TOKEN` | رلهٔ قدیمی میزبان فیلتر (اختیاری) |
| `PROMO_TEXT` | تبلیغ محلی (اختیاری) |

## ساختار مخزن

```
worker.js          ← ربات (همهٔ تنظیمها از bindings میآید)
install.sh         ← نصب تکخطی
update.sh          ← آپدیت پشتیبان (کرون اختیاری)
deploy-tool.py     ← ابزار دیپلوی روی ورکر
promo.txt          ← تبلیغ مرکزی
docs/              ← آموزش تصویری و راهنماها
```

ساختهشده با ❤️ برای کسانی که کار روزمرهٔ مدیریت دامنه و سرور را به تلگرام سپردهاند.
