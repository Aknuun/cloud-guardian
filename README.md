# نگهبان ابری ☁️

ربات مدیریت کامل دامنه، DNS، پنل‌ها و مانیتورینگ — اجرا در **Cloudflare Workers** با تلگرام.

- مدیریت رکوردهای DNS روی کلادفلر و آروان (A / CNAME / AAAA / TXT / SRV / MX)
- تشخیص زیردامنهٔ فندی و تعویض خودکار آن (Host Filter) برای ورکرها روی دامنه‌های دارای فیلتر
- مانیتور SSL، انقضای دامنه، پایش منابع سرور از طریق «رلهٔ SSH»، گزارش پرمصرف‌ها
- افزودن/اعلان سرورهای SSH از داخل ربات (بدون نیاز به پورت ۲۲ باز از سمت کلادفلر)
- ساخت خودکار ساب‌دامه برای رله (با فرستادن فقط آی‌پی، ربات خودش رکورد A می‌سازد)
- احراز پنل‌ها (پاسارگارد و…) و آپدیت اعلان، یادآوری، جستجوی هوشمند IP/نام

---

## نصب تک‌خطی (روی یک سرور لینوکسی)

```bash
bash -c "$(curl -sL https://raw.githubusercontent.com/Aknuun/cloud-guardian/main/install.sh)"
```

> سرور فقط برای دیپلوی و آپدیت خودکار لازم است؛ ربات روی ورکر کلادفلر اجرا می‌شود. حتی یک VPS ارزان‌قیمت کافی است.

اسکریپت از شما می‌پرسد:
1. **توکن API کلادفلر** — با دسترسی‌های `Workers Scripts Edit`، `Workers KV Storage Edit`، `Zone DNS Edit` (از https://dash.cloudflare.com/profile/api-tokens)
2. **نام ورکر** (پیش‌فرض `cloud-guardian`)
3. **توکن ربات تلگرام** — از [@BotFather](https://t.me/BotFather)
4. **شناسهٔ عددی تلگرام مدیر** — عدد، از [@userinfobot](https://t.me/userinfobot)

بعد از نصب:
- در تلگرام روی ربات `/start` بزنید.
- فایل تنظیمات در `~/.cloud-guardian/config.json` (فقط شما) ذخیره می‌شود.

## آپدیت خودکار 🔄

نصب‌کننده یک کرون (هر ۳۰ دقیقه) می‌گذارد که نسخهٔ جدید را از همین مخزن گرفته و بدون دخالت مشتری روی ورکر دیپلوی کند:

```bash
curl -fsSL -o ~/.cloud-guardian/update.log -L --max-time 90 ...   # به‌صورت خودکار
```

اجرای دستی هم سراغی دارد:

```bash
~/.cloud-guardian/update.sh
```

## راه‌اندازی رلهٔ SSH (برای بخش «سرورها»)

اگر بخش سرورهای SSH نیاز دارید، روی یک VPS:

```bash
sudo bash -c "$(curl -sL -H 'Accept: application/vnd.github.raw' 'https://api.github.com/repos/Aknuun/cloud-guardian-relay/contents/srv-relay-install.sh?ref=main')"
```

سپس در ربات: «🖥 سرورها ← ℹ️ راهنمای رله ← 🔧 تنظیم رله» — فقط آی‌پی را بفرستید؛ ربات خودش `rel.دامنه → آی‌پی` را می‌سازد.

## تبلیغات 📢

روی `/start` متن تبلیغ نمایش داده می‌شود: **«طراحی توسط @panelSazFilterBot»**

دو راه تغییر، **بدون نیاز به آپدیت مشتری**:
1. مدیر (داخل ربات): `/promoset متن دلخواه` — روی همان ورکر اثرگذار است.
2. مرکزی: فایل `promo.txt` در همین مخزن را ویرایش کنید؛ همهٔ ربات‌های نصب‌شده حداکثر تا ۱۲ ساعت آن را نشان می‌دهند.
   (اگر تبلیغ مرکزی را نمی‌خواهید، متغیر `PROMO_URL` را در دشبورد ورکر خالی/تغییر دهید و یا با `/promoreset` به حالت مرکزی برگردد.)

## متغیرهای اختیاری ورکر (bindings)

| متغیر | توضیح |
|---|---|
| `WHOIS_API_KEY` / `WHOIS_API_PROVIDER` | API اعتبارسنجی انقضای دامنه |
| `GLOBALPING_TOKEN` | توکن Global Ping برای چک IPv4 |
| `SRV_RELAY_URL` / `SRV_RELAY_TOKEN` | رلهٔ SSH پیش‌فرض (بدون نیاز اگر از ربات ثبت کنید) |
| `HF_RELAY_URL` / `HF_RELAY_TOKEN` | رلهٔ قدیمی میزبان فیلتر (اختیاری) |
| `PROMO_TEXT` | متن تبلیغ محلی (اختیاری) |

## ساختار

```
worker.js        ← ربات (برای خودتان، همهٔ تنظیم‌ها از bindings می‌آید)
install.sh       ← نصب تک‌خطی
update.sh        ← آپدیت خودکار
deploy-tool.py   ← دیپلوی روی ورکر کلادفلر
promo.txt        ← تبلیغ مرکزی
```

پیام‌ها/گزارش‌ها فارسی هستند. ساخته‌شده با ❤️ برای مدیریت آسان‌تر.
