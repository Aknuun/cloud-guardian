## خلاصه

ربات تلگرامی مدیریت **دامنه، DNS، پنل پاسارگارد و سرورها** که کامل روی **Cloudflare Workers** اجرا می‌شود.

`☁️ کلودفلر` · `🇮🇷 آروان` · `🇩🇪 هتزنر` · `🟢 لینود` · `🖥 مانیتورها`

### دکمه‌های عملیاتی

- 🧭 **تعویض خودکار ساب فیلتر**: وقتی دامنهٔ هاست پاسارگارد شما در ایران فیلتر بشه، ربات برای همان آی‌پی یک دامنهٔ جدید با اسم جدید می‌سازه و در پنل پاسارگارد جایگزین می‌کنه.
- 🇩🇪 **هتزنر**: ایجاد، حذف، اسنپ‌شات و مدیریت کامل سرورهای هتزنر.
- 🟢 **لینود**: ایجاد، حذف، اسنپ‌شات و مدیریت کامل سرورهای لینود.
- ☁️ **کلودفلر**: مدیریت کامل DNS — افزودن، ویرایش و حذف رکورد، تنظیمات SSL/TLS و عملیات گروهی.
- 🇮🇷 **آروان**: مدیریت دامنه‌ها و رکوردهای آروان کلاد.
- 🔍 **جست‌وجو در همه**: جست‌وجو در همهٔ اکانت‌ها بر اساس نام، دامنه یا آی‌پی.
- 🖥 **سرورها**: مدیریت سرور و نصب/آپدیت نود پاسارگارد از طریق «رلهٔ SSH».
- 🔐 **مانیتور SSL**: هشدار نزدیک شدن به انقضای گواهی SSL.
- 🗓 **مانیتور انقضای دامنه**: هشدار خودکار انقضای دامنه‌ها (۶۰، ۳۰، ۱۴، ۷، ۳ و ۱ روز مانده).
- 🖥 **مانیتور نود پاسارگارد**: هشدار قطع/وصل شدن نود + وب‌هوک + همگام‌سازی با پنل.
- 📡 **مانیتور سرورها**: پایش CPU، رم و دیسک سرورها از طریق رلهٔ SSH.
- 🔥 **گزارش بد مصرف پاسارگارد**: شناسایی مصرف‌های بیش از حد (مشکوک به اشتراک‌گذاری ساب).
- ☁️ **سهمیهٔ کلادفلر**: پایش مصرف روزانهٔ ورکر و توقف خودکار در سقف.
- ⏰ **یادآور**: یادآوری انقضای سرور و دامنه.

## نصب (از طریق سرور روی کلادفلر)
روی سرور موقت لینوکسی اجرا کنید:

```bash
bash -c "$(curl -sL https://raw.githubusercontent.com/Aknuun/cloud-guardian/main/install.sh)"
```

اسکریپت به ترتیب میپرسد: توکن API کلادفلر → نام ورکر (پیشفرض `cloud-guardian`) → توکن ربات → شناسهٔ مدیر. تنظیمات در `~/.cloud-guardian/config.json` (فقط شما) ذخیره میشود.
> سرور فقط «ابزار نصب» است. بعد از نصب میتوانید آن را حذف کنید؛ ربات مستقل کار میکند.
